# 背景処理のページ非依存検証

Firefox MV3のイベントページが、Content Scriptやポップアップを表示せずに予約されたイベントを処理できるか確認する独立した試験拡張です。音声・マイク・Native Messaging・Webページの内容にはアクセスしません。常時表示UIの試作とは別に一時読み込みできます。

1. `about:debugging#/runtime/this-firefox` で `assistant-ui/lifetime-probe/manifest.json` を一時読み込みします。
2. 拡張メニューの「背景処理の検証」を開き、「30秒後の処理を予約」を押します。
3. メニューを閉じ、`about:addons` などContent Scriptを表示できないページで30秒以上待ちます。待機中は検証用ポップアップを開かないでください。
4. 拡張メニューを再度開き、「処理を実行しました」と時刻が表示されることを確認します。Firefoxの起動直後・拡張の再読み込みをまたぐ試験ではありません。

これは**予約イベントがページ非依存で実行されたこと**だけを確認する試験です。背景処理が30秒間常駐した証拠ではなく、イベントページが停止していたかどうかも分かりません。Wake Wordの連続待機、実音声、Native Messagingの継続接続、拡張間メッセージ、Firefox再起動後の復帰を証明するものではありません。アラームが遅延する場合があるため、すぐ結果が出なければ少し待って再確認します。

処理結果はこの試験拡張のローカルストレージにだけ保存します。試験は一回限りで繰り返し動作せず、拡張を削除・再読み込みするとFirefoxが予約を破棄する場合があります。
