# 音声アシスタント共通UI 試作

第1段階の表示・ドラッグ・状態共有を検討するFirefox拡張です。状態は操作メニューで切り替える**試作表示**で、音声serviceへの接続、Wake Word、録音、認識、操作の配送は行いません。THE SESSION TOOLSとVoice Editorの既存の音声操作は変更しません。

## 読み込みと確認

1. Firefoxの `about:debugging#/runtime/this-firefox` で「一時的なアドオンを読み込む」を選び、`assistant-ui/manifest.json` を読み込みます。
2. HTTPまたはHTTPSのページを開き、左上に `試作：未接続` が表示されることを確認します。既に開いていたページは再読み込みしてください。
3. パネルをドラッグして位置を変更し、別の対象ページや再読み込み後にも表示位置が引き継がれることを確認します。
4. 拡張のメニューで「表示する状態」を切り替え、ページ側の文字が変わることを確認します。選択は表示試験用で、実際の音声サービス状態ではありません。
5. 複数タブ・ウィンドウ、Split View、タッチ操作、表示制限ページから対象ページへの復帰を確認します。

表示対象は付与されたホスト権限内の `<all_urls>` です。Firefoxの権限設定、拡張ページ、接続エラー画面、ブラウザー内部ページ、PDFビューアー、保護されたサイトなどでは表示できません。通常のページ内でも、ページの最前面表示機能やDOMの変更により、最前面に維持できない場合があります。別拡張のページへの表示や、Firefox自体のUIより前面に出すことはできません。

試作の状態と位置は拡張のローカルストレージに保持し、ページがなくても状態を取得・変更できます。ただし、現段階では音声処理そのものが未接続です。表示不可ページでの音声操作の継続や、Firefox MV3の背景処理の寿命・再開は後続段階で設計・実機検証します。

表示不可ページを開いている間の予約イベント処理を確認する、別の[背景処理検証](lifetime-probe/README.md)も用意しています。音声・マイクは使用せず、常時待機を検証する試験ではありません。

全サイトへの表示には広いホスト権限が必要です。この試作はページのテキストを読み取らず、音声や認識結果の送信も行いません。常時表示を実際に有効化する前に、ユーザーのFirefoxで権限を確認してください。

```bash
node tests/test_assistant_ui.cjs
```
